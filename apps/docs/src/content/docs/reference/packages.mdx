Every row below is copied from `packages/*/package.json` (`name`, `version`, `exports` keys, `private` absent/false). All packages are **published to the public registry** (`core` 1.0.0, `gateway-tap`/`gateway-myfatoorah`/`testkit` 1.0.1–1.0.2, `gateway-hesabe` 0.1.0, engines/stores/integrations 0.1.1–0.1.2, contracts/sql-foundation 0.1.0). Install with `bun add @paykernel/<name>` or `npm install @paykernel/<name>`.

:::caution[Names]
The folder `packages/observability` publishes as **`@paykernel/opentelemetry`**. Never import or install `@paykernel/observability`.
:::

## Subpaths that exist (do not invent others)

Import paths must match `exports` keys. A subpath that is not in the table **does not exist**.

| Package | Legal specifiers |
| --- | --- |
| `@paykernel/opentelemetry` | `@paykernel/opentelemetry`, `@paykernel/opentelemetry/otel` |
| `@paykernel/store-postgres` | `@paykernel/store-postgres`, `/bun-sql`, `/postgres-js`, `/pg`, `/drizzle` |
| `@paykernel/store-redis` | `@paykernel/store-redis`, `/bun`, `/upstash`, `/ioredis`, `/node-redis` |
| `@paykernel/store-sqlite` | `@paykernel/store-sqlite`, `/bun`, `/node`, `/better-sqlite3` |
| `@paykernel/store-turso` | `@paykernel/store-turso`, `/serverless`, `/libsql` — **no** `/sync` |
| `@paykernel/store-d1` | `.` only |
| `@paykernel/store-durable-objects` | `.` only — never one global Durable Object |

Redis is **optional**. Local SQLite is **single-host**. `:memory:` is one process. Turso is **remote multi-host**. D1 ≠ Durable Objects ≠ Turso ≠ local SQLite. Memory stores (`@paykernel/testkit`) are **NON-PRODUCTION**. No published adapter declares `coordinationScope: "multi-region"`. Importing a store package does **not** apply DDL — migrate explicitly.

## Failure path (wrong specifier)

The folder `packages/observability` is **not** an import path. Use the publish name (root or `./otel` subpath):

```ts
import { createOpenTelemetryBridge } from "@paykernel/opentelemetry";
// same factory, no static OTEL import:
import { createOpenTelemetryBridge } from "@paykernel/opentelemetry/otel";
```

Turso has **no** `./sync` export. Legal driver subpaths:

```ts
import { createLibsqlStores } from "@paykernel/store-turso/libsql";
```

Store factories and exact export names: [stores](/stores). Runtime export list for core: [core API](/reference/core-api).
